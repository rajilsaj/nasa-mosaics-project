# NASA–MOSAICS / ISL — Cassini ELS & Mars Dust Pipeline 

A compact internal research repository (ISL & NASA/JPL) containing two related projects:

- Mars Dust (VERSA): data collection, labeling, and a lightweight two-stage LSTM pipeline for detecting Martian dust-devils from pressure sensor data.
- Cassini CAPS/ELS: scripts and parsers to mirror and process Cassini Electron Spectrometer (ELS) products for context and validation.

Quick start
1. Create and activate a Python virtual environment.
2. Install required packages (see `Mars-Dust/requirements.txt` for that subproject).
3. Explore `Mars-Dust/models/` for training and evaluation scripts.
