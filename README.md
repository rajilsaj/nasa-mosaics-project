# 🚀 NASA-MOSAICS-Project

Cassini Spacecraft Data Analysis & Martian Dust Devil Detection  
**A data science project for NASA's MOSAICS program**

---

## 🌍 Project Description

This repository contains Python scripts and Jupyter notebooks for analyzing:
- **Cassini spacecraft datasets**
- **Martian atmospheric data**, focusing on dust devil detection

The project leverages data science tools like `pandas`, `numpy`, and `matplotlib` to explore, visualize, and extract meaningful insights from planetary datasets.
